DHCP Process (DORA)

How a device with no IP (Internet Protocol) address yet gets one automatically, in exactly four steps, most of them broadcasts.

A walk-in guest with no reservation

Picture a traveler arriving at a row of hotels with no reservation, asking loudly enough for every hotel on the street to hear: "does anyone have a room?" That's DHCP's (Dynamic Host Configuration Protocol's) entire opening move, and it has to be shouted, since the device doesn't have an IP address yet and can't address a single specific server directly. One hotel calls back: "yes, room 204 is free, here are the house rules." The traveler shouts their acceptance loud enough for every other hotel to hear too, in case more than one offered a room, so the others know to stop holding theirs. The chosen hotel confirms: checked in.

DORA: Discover, Offer, Request, Acknowledge

StepDirectionBroadcast?Contains
DiscoverClient → segmentYes"I need an IP address"
OfferServer → segmentUsuallyProposed IP, lease time, subnet mask, gateway, DNS servers
RequestClient → segmentYes"I accept the offered IP", visible to every server that offered
AcknowledgeServer → segmentUsuallyConfirms the lease is now active
WHY DISCOVER AND REQUEST ARE BOTH BROADCASTS

Discover has to be a broadcast because the client genuinely has no address to send from or to yet. Request is a broadcast for a different reason: if more than one DHCP server replied with an Offer, broadcasting the acceptance lets every server see which offer won, so the ones that lost know to release the address they'd tentatively reserved instead of holding it forever.

WHAT HAPPENS WHEN THE CLIENT AND SERVER AREN'T ON THE SAME SEGMENT

Broadcasts don't cross routers (see Collision Domain vs Broadcast Domain), so a DHCP server living on a different subnet would never hear a client's Discover at all. A DHCP relay agent, usually the local router's own ip helper-address configuration, listens for these broadcasts and forwards them as a unicast to the real DHCP server elsewhere, then relays the replies back the same way.
